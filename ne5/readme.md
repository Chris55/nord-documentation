## Nord Electro 5 File Structures

This part documents the Nord Electro 5 file structures. It was decoded from files written by the instrument and by
Nord Sound Manager, changing one setting at a time, and checked on the instrument (OS 2.04). It is not officially
supported by Nord Keyboards / Clavia DMI AB. While we certainly hope this document is useful, none of the authors or
contributors place any guarantees as to the accuracy of the data.
